# Arkanoid

Вверху поля множество прямоугольных блоков. Внизу горизонтально перемещается каретка. По полю летает «мяч», отражаясь от стен, блоков и каретки. Если мяч попадает вниз (мимо каретки) — теряется жизнь.

## Типы блоков
1. **Неразрушаемые** – мяч отскакивает, блок остаётся.
2. **С бонусом** – при разрушении вниз падает бонус.
3. **Ускоряющие** – увеличивают скорость мяча при ударе.
4. **С уровнем здоровья** – несколько попаданий до исчезновения. За каждое попадание +1 очко.
5. **Обычные** – разрушаются с одного удара.

## Бонусы
- **Big / Small Paddle** – увеличивают / уменьшают ширину платформы (ограничения 60–300 пикселей).
- **Fast / Slow Ball** – ускоряют (×1.3) / замедляют (×0.8) мяч.
- **Sticky** – следующее касание платформы приклеивает мяч; запуск пробелом.
- **Bottom Wall** – одноразовое дно: отражает мяч один раз и исчезает.
- **Random Trajectory** – случайно меняет направление мяча (угол ±60°).

## Возможности
- Управление платформой (A / D)
- Отскок мяча от стен, блоков и платформы (с вычислением стороны удара)
- Система очков и жизней (3 жизни, сброс счёта при поражении)
- Генерация уровня из блоков разных типов (6 строк × 12 столбцов)
- Падающие бонусы с различными эффектами (скорость 240 пикселей/сек)

## Используемые технологии
- C++20
- SFML 3.0
- ООП, полиморфизм, паттерн Фабрика
- `constexpr` для настроек
- `std::mt19937` для случайных чисел

## Структура проекта (основные классы)
- **Game** – главный игровой цикл, окно, обработка ввода, счёт, жизни.
- **Ball** – шарик: позиция, скорость, отрисовка, сброс со случайным углом.
- **Paddle** – платформа: управление, размер, границы, `getBounds`.
- **Block** – абстрактный класс с методами `onHit`, `getBounds`, `isDestroyed`. Наследники: `NormalBlock` (красный, 1 HP), `UnbreakableBlock` (серый, неразрушаемый), `SpeedBlock` (жёлтый, ускоряет), `BonusBlock` (голубой, спавнит бонус).
- **BlockFactory** – создание блоков по категории.
- **Level** – генерация и хранение блоков (`vector<unique_ptr<Block>>`), отрисовка.
- **Bonus** – абстрактный базовый класс: обновление падения, отрисовка, `getBounds`. Наследники: 7 конкретных бонусов, каждый переопределяет `apply`.
- **BonusFactory** – создание бонусов по типу.
- **BonusManager** – управление падающими бонусами (`vector<unique_ptr<Bonus>>`), проверка пересечения с платформой и применение.
- **CollisionManager** – обработка столкновений мяча с блоками: вычисление стороны удара, вызов `block->onHit`.
- **Physics** – столкновения со стенами и платформой (расчёт силы отскока в зависимости от места попадания).
- **Config.h** – все игровые константы (`constexpr`).
- **Utils.h/.cpp** – `rnd()` для случайных чисел на `std::mt19937`.

## Настройка (Config.h)
В `Config.h` собраны все параметры игры: размер окна, скорость мяча, размеры блоков, ограничения ширины платформы, множители скорости, диапазоны случайных углов, скорость падения бонусов и т.д. Измените эти значения для баланса.

## Как запустить

### 1. Скачать SFML 3.0
[https://www.sfml-dev.org/download/sfml/3.0.0/](https://www.sfml-dev.org/download/sfml/3.0.0/)  
Распаковать, например, в `C:\SFML`

### 2. Настройка Visual Studio
- **C++20:** `Project → Properties → C/C++ → Language → C++ Language Standard → ISO C++20 Standard (/std:c++20)`
- **Include директории:** `Project → Properties → C/C++ → General → Additional Include Directories` → добавить `C:\SFML\include`
- **Library директории:** `Project → Properties → Linker → General → Additional Library Directories` → добавить `C:\SFML\lib`
- **Библиотеки (Debug):** `Project → Properties → Linker → Input → Additional Dependencies` → добавить  
  `sfml-graphics-d.lib`  
  `sfml-window-d.lib`  
  `sfml-system-d.lib`
- **DLL:** скопировать из `C:\SFML\bin` в папку с `.exe`  
  `sfml-graphics-d-3.dll`, `sfml-window-d-3.dll`, `sfml-system-d-3.dll`

## Управление
- **A / D** – движение платформы
- **Space** – запуск мяча (если прилип)
- **ЛКМ** – закрытие окна (крестик)
